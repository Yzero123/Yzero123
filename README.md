## 💡 工作方式

- **先跑通再优化**：每条链路先有可执行的最小版本，再补质量门与恢复逻辑。
- **交付即文档**：公开的代码要能被别人按 README 独立跑通；跑不通就把边界说清楚。
- **数据驱动**：指标用脚本算出来，不用估。CNN 仓库里的准确率就是 `evaluate.py` 实测的。
